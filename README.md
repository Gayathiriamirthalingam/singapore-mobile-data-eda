# Singapore Mobile Data Usage EDA

## Overview
An exploratory data analysis of Singapore's mobile data consumption 
from 2004 to 2018, using data from data.gov.sg.

## Key Findings
- Mobile data usage grew from near zero in 2004 to over 20 petabytes by 2018
- Growth slowed around 2014–2016, likely due to expansion of public WiFi
- Highest growth rates were seen between 2009–2012

## Tools Used
- Python, Pandas, Matplotlib
- Google Colab
- Data source: data.gov.sg
